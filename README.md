# FrioMax Landing Page

Site institucional de alta conversão para a FrioMax Climatização.

## 🚀 Como rodar o projeto localmente

Para abrir o site no seu navegador com atualização automática (Live Reload), siga estes passos:

1. Abra o terminal na **pasta raiz** do projeto (`d:\Guilherme - friomax`).
2. Certifique-se de que você está na pasta correta (não entre na pasta `assets` ou `css`).
3. Execute o comando:
   ```bash
   npm run dev
   ```
4. O navegador abrirá automaticamente em `http://localhost:3000`.

## 📁 Estrutura de Pastas
- `assets/`: Imagens e ícones.
- `css/`: Arquivos de estilo (CSS).
- `js/`: Lógica e animações (JavaScript).
- `index.html`: Página principal.

## 🛠️ Tecnologias
- HTML5 / CSS3 / JavaScript Vanilla
- [Lucide Icons](https://lucide.dev/)
- [ScrollReveal](https://scrollrevealjs.org/)
- [BrowserSync](https://browsersync.io/) (Servidor de desenvolvimento)
